# Worksheet build request.
#
# One ws_id per line-that-matters. The build workflow reads the first non-empty,
# non-comment line and builds exactly that worksheet.
#
# To request a build while the factory lives on a feature branch:
#
#   echo WS-06-team-readiness-scorecard > worksheets/_build-request.txt
#   git commit -am "build: WS-06" && git push
#
# One worksheet per push, on purpose: one run, one worksheet, a fresh context
# window per stage. Once the factory is on the default branch, the queue
# workflow and the `stage:build` issue label replace this file.
#
# The leading underscore keeps Quarto from treating this as a renderable input.
